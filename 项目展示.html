项目简介

本项目是湖南工业大学软件工程课程大作业，旨在为校园宿舍提供智能化的报修管理与服务评价解决方案。系统实现"报修-派单-维修-验收-评价"全流程闭环管理，解决传统报修流程繁琐、响应慢、信息不透明的问题。

01 可行性分析报告

1. 技术可行性

采用业界成熟主流技术栈：Spring Boot + MyBatis-Plus + MySQL + Vue 3 + uni-app。所有开发工具均可免费获取，技术风险低。

2. 经济可行性

开发成本极低（人力零成本 + 全部开源免费工具），预期效益明显（报修时间从5分钟缩至1分钟）。

3. 运行可行性

学生习惯微信小程序（接受度高），维修工界面简洁（简单培训可用），管理员Web后台直观。

4. 法律可行性

项目为教育目的课程作业，使用开源技术，无法律风险。

结论：项目完全可行，建议启动开发。

03 概要设计说明书

系统架构

采用前后端分离B/S架构，三层设计：表现层（小程序+Web）→ 业务逻辑层（Spring Boot）→ 数据访问层（MySQL+Redis）

核心模块

子系统模块数主要功能
学生端6个认证、报修申请、进度查询、评价、历史、通知
维修端3个工单接收、工单处理、工单查询
管理端6个工单管理、智能派单、人员管理、统计、公告、评价

工单状态流转

PENDING(待派单) → DISPATCHED(已派单) → IN_PROGRESS(维修中) → COMPLETED(已完成) → EVALUATED(已评价)

04 详细设计说明书

6个核心模块详细设计

模块功能类型说明
报修申请模块增加表单验证→编号生成→入库→触发派单
进度查询模块查询分页列表+状态筛选+时间轴展示
工单处理模块修改接单（状态→维修中）、完工（状态→已完成）
人员管理模块增删改维修人员CRUD操作
统计分析模块统计多维度聚合查询+ECharts图表+Excel导出
智能派单模块流程处理加权评分算法（技能40+区域30+负载20+评价10）
