# 校园宿舍智能报修与服务评价系统

## 项目简介
本项目是湖南工业大学软件工程课程大作业，为校园宿舍提供智能化报修管理与服务评价解决方案，实现“报修-派单-维修-验收-评价”全流程闭环管理。
