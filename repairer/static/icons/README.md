# TabBar 图标说明

请将以下图标放置在本目录下（建议 40x40px 的 PNG 图片）：

- `hall.png` - 工单大厅图标（灰色）
- `hall-active.png` - 工单大厅图标（激活态，#1677FF）
- `order.png` - 我的工单图标（灰色）
- `order-active.png` - 我的工单图标（激活态，#1677FF）
- `mine.png` - 我的图标（灰色）
- `mine-active.png` - 我的图标（激活态，#1677FF）

如暂未准备图标，可以删除 pages.json 中 tabBar.list 的 iconPath 和 selectedIconPath 字段。
